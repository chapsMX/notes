# Chapsbox 📦

Tu segundo cerebro en la nube.

## Descripción

Chapsbox es una aplicación web para capturar, organizar y buscar toda tu información personal: links, fotos, notas, recordatorios, lista de compras y más.

## Stack

- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS
- **Backend:** Supabase (PostgreSQL + Auth)
- **Deployment:** Vercel (recomendado)

## Instalación

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## Variables de Entorno

```bash
NEXT_PUBLIC_SUPABASE_URL=https://...supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
```

## Características

- ✅ Búsqueda en tiempo real
- ✅ Categorías y tags
- ✅ Colecciones (c13studio, etc)
- ✅ Lista de compras dinámica
- ✅ Autenticación Supabase
- 🚀 Más en desarrollo...

## Desarrollo

```bash
npm run dev      # Desarrollo local
npm run build    # Build para producción
npm start        # Inicia servidor producción
npm run lint     # Lint de código
```
